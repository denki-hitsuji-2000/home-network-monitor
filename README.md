# Home Network Monitor Public Files

このリポジトリは、noteで投稿している
**「家庭用ネットワーク監視プロジェクト」** に関する公開用ファイルを置くためのリポジトリです。

自宅LANの見える化、ネットワーク監視、PowerShellによるスキャン処理、ASP.NET Core / Razor Pages によるダッシュボード表示などを、学習しながら構築しています。

## About this project

このプロジェクトでは、家庭内LANに接続されている機器を確認し、以下のような情報を見える化することを目的としています。

* IPアドレス
* ホスト名
* MACアドレス
* ベンダー名
* スキャン日時

現在は、PowerShellスクリプトでLAN内の端末情報を取得し、その結果をCSV / JSONとして出力しています。
出力されたデータは、ASP.NET Core / Razor Pagesで作成したダッシュボードから表示する構成です。

## Repository purpose

このリポジトリは、プロジェクト全体のソースコードをすべて公開するものではありません。

note記事で解説している内容に関連する、以下のような公開可能なファイルを置くために使用します。

* PowerShellスクリプト
* 設定ファイルのサンプル
* 補助ファイル
* 記事内で参照するサンプルコード
* 学習用・検証用の公開ファイル

実際の家庭内LAN情報、ログファイル、個人環境に依存する設定値などは含めません。

## Current files

現時点では、主に以下のようなファイルを公開する予定です。

```text
scripts/
  Convert_OUI.ps1

config/
  settings.example.json
```

### Convert_OUI.ps1

IEEEのOUI情報CSVを読み込み、MACアドレスの先頭3バイトからベンダー名を検索できるようにするための `oui.json` を作成するスクリプトです。

### LanScan.ps1

家庭内LANのIPアドレス範囲をスキャンし、応答のあった端末について、IPアドレス、ホスト名、MACアドレス、ベンダー名などをCSV / JSONに出力するスクリプトです。

### settings.example.json

スキャン範囲などを指定する設定ファイルのサンプルです。
実際に使用する場合は、自分の環境に合わせて内容を変更してください。

## OUI data

OUI情報は、IEEEの公開データを使用します。

`oui_raw.csv` は、このリポジトリには含めていません。
必要に応じて、IEEEのWebサイトから取得してください。

また、`oui.json` は `Convert_OUI.ps1` を実行して作成するため、このリポジトリには含めない予定です。

## Notes

このリポジトリの内容は、学習・検証目的で作成しています。

スクリプトを使用する場合は、自分が管理しているネットワーク、または許可を得ているネットワークでのみ実行してください。
自分が管理していないネットワークに対して、無断でスキャンを行わないでください。

また、環境によってはPowerShellの実行ポリシー、ネットワーク設定、セキュリティソフト、Windowsファイアウォールなどの影響により、同じ結果にならない場合があります。

## Environment

* Windows 11

* Task Scheduler
* ASP.NET Core / Razor Pages
* IIS
* Home LAN environment
